================================================================================
1. Install dependencies:
   $ pip install -r requirements.txt

2. Run demo:
   $ python examples/demo_analysis.py

3. Start API server:
   $ python -m src.api.main

4. Use as library:
   from src.core.agent import DQDAAgent
   agent = DQDAAgent()
   result = agent.analyze({...})
